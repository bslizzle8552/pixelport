# Upstream license provenance

Unmodified license texts for components shipped in the onedir bundle:

- `tcl-license.terms`: Tcl 8.6.15, https://raw.githubusercontent.com/tcltk/tcl/core-8-6-15/license.terms
- `openssl-LICENSE.txt`: OpenSSL 3.0.18, https://raw.githubusercontent.com/openssl/openssl/openssl-3.0.18/LICENSE.txt
- `zlib-LICENSE`: zlib 1.3.1, https://raw.githubusercontent.com/madler/zlib/v1.3.1/LICENSE

Other notices are copied at build time from the exact installed Python runtime,
Tk script directory, and Pillow/pywin32/PyInstaller wheel license metadata. Pillow's
complete wheel license includes its bundled codecs. The spec copies notices only,
not wheel source trees or local build metadata. See ../THIRD_PARTY_NOTICES.md.
